## Descrição

![Demonstração do Projeto](./public/demo.gif)

O objetivo do desafio é criar uma aplicação ao modelo ToDo onde o usuário possa criar novas tarefas e marcá-las como finalizadas, bem como visualizar o status de quantas tasks ele já finalizou e o total de tasks.

Este projeto é o primeiro desafio da trilha de React da Rocketseat. Ele foi desenvolvido utilizando Vite, React e TypeScript, seguindo boas práticas de organização e estruturação de código modernas.

## 🛠️ Principais Tecnologias

Este projeto utiliza as seguintes tecnologias e bibliotecas:

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/) 
- [Vite](https://vitejs.dev/) 

## 🚀 Como executar o projeto

Certifique-se de ter o **Node.js** instalado (versão recomendada: `>=18`).

Clone o repositório e utilize um dos fluxos abaixo:

### 🔄 Desenvolvimento (servidor local com hot reload)

Com **npm**:

```bash
npm install
npm run dev
```

Com **yarn**:

```bash
yarn install
yarn dev
```

A aplicação estará disponível em:

```
http://localhost:5173
```

### 📦 Produção (build e execução do preview)

Com **npm**:

```bash
npm install
npm run build
npm run preview
```

Com **yarn**:

```bash
yarn install
yarn build
yarn preview
```

A aplicação estará disponível em um endereço local exibido no terminal, normalmente algo como:

```
http://localhost:4173
```
